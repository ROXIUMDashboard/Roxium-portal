Admin · portal controls

One global area for the whole site — create clients, manage who can sign in, configure KPI sources, and monitor sync. Not part of any single client's dashboard.

New client onboarding

Creates the practice with standard deliverables, roadmap and video pipeline. On create, the portal tries to find the client's workbook in the master folder and detect its source tabs automatically — anything unclear is left for you to confirm under Reporting & KPI.

Platform administrators

Who can open this Admin panel. Make admin grants full portal-admin access by email — the person must have signed in at least once first. The last administrator can't remove themselves, so you're never locked out.

Practice access & invites

Send invite emails a sign-in link and adds the address to the allowlist. Uncheck “Send email” to allowlist only — the doctor can sign up themselves with that same email (Option B). Practice owners invite their own staff from the Invite team tab in their dashboard.

Reporting workbooks & KPI sources

Each client has one master workbook (in the global folder set under System) with a tab per channel. Use Find in master folder and Detect tabs, pick each source's tab from the dropdown, then Deploy setup. Sync also runs automatically every 2 hours.

Master Reporting Drive Folder — global, for the whole system

Each client's “Find in master folder” searches this folder by practice name. Share the folder with the backend service account so it can read it.

Manual sync & debugging

Manual/debug — “Deploy setup” on a client also runs this. Sync runs automatically every 2 hours.

Invite team members

Add as many colleagues as you need — each gets their own login scoped to this practice only. Send invite also adds them to the allowlist automatically.

Team · controls

Controls for the practice you currently have open. Everything you save updates that client's view instantly. (Client & access management lives in the Admin tab.)

Deliverables, roadmap & video pipeline

Deliverables: edit any field, dropdown to change status, ✕ to remove, "+ Add" for new ones. Roadmap: the date under each milestone is editable (dates are set automatically per practice at kickoff — change one only if a date shifts). Video pipeline: drag a card between stage columns to move it, or click a card to rename it / flag it blocked. The surgeon sees clean, read-only versions.

Manual Monthly KPIs — fallback / manual layer

The primary KPI source is the client's reporting workbook + source tabs (Admin → Reporting & KPI). Use this manual layer for hand-entered months or overrides when automation isn't available. Each month is its own saved snapshot — editing one never changes another. Pick the month, enter values, Save. Download KPI CSV exports the saved months.

Danger zone

Reset returns this practice to a clean slate: it permanently deletes every KPI month, the activity feed, all notifications and stage history, and resets all deliverables, milestones and videos to their starting state. This cannot be undone.
